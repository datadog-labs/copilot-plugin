Tab / Enter
Move between controls and activate them. Arrow keys within focused form controls remain native.

Long content: card backs and some narrow-screen fronts scroll. Focus a card’s content area, then use Page Up / Page Down to read. Wiki provides every face in an uninterrupted reader.

Search: keywords match across titles, front points, field notes, code and source references. All entered words must match; case is ignored. No search is sent anywhere. Clearing restores the full reader.

Printing: Print all includes all 36 cards and both faces, plus the source register, regardless of the active search or mode. Use your browser’s print options to save a PDF if desired.

Fullscreen: uses the browser’s fullscreen capability when available. If a preview blocks it, open the HTML locally. Your browser’s Escape key exits fullscreen.

Access: reduced-motion preferences are honored. No automatic slide advance. No authentication, external requests, telemetry or browser storage. External source links open only when you choose them.
